A structured, topic-by-topic comparison of two of Asia's premier financial hubs and global cities.

## Quick Summary

| Dimension | Hong Kong | Singapore |
|-----------|-----------|-----------|
| **Population** | ~7.5M | ~5.9M |
| **GDP per capita (PPP)** | ~$75,000 | ~$133,000 |
| **Tax regime** | Territorial, low rates | Territorial, low rates + incentives |
| **Housing affordability** | Least affordable globally | High but managed via HDB |
| **Healthcare** | Public + private, high quality | Public + private, world-class |
| **Public transport** | MTR (world-class) | MRT (world-class) |
| **Safety** | Very safe | Extremely safe |
| **Climate** | Subtropical, typhoons | Tropical, consistent |
| **Language** | Cantonese, English, Mandarin | English, Mandarin, Malay, Tamil |
| **Political system** | SAR of China | Parliamentary republic |
