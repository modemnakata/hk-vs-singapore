## Detailed Category Comparison

### Housing — The Biggest Differentiator

| Aspect | Hong Kong | Singapore |
|--------|-----------|-----------|
| **1BR Rent (expat area)** | HK$18-30k / US$2,300-3,800 | S$2,800-4,500 / US$2,100-3,300 |
| **3BR Rent (family)** | HK$35-80k / US$4,500-10,200 | S$3,500-6,500 / US$2,600-4,800 |
| **Purchase price (psf)** | HK$140k+ (private) | S$1,600-3,500 (condo), HDB S$500-700 |
| **Price-to-income** | 23.2x (world #1) | ~5-7x (HDB), ~12x (condo) |
| **Homeownership** | ~50% | 89% (HDB) |
| **Foreigner barriers** | 15% BSD + 15% SSD | 60% ABSD + BSD |
| **Leasehold** | 50-999 years (mostly 50-99) | 99 years (HDB/condo), freehold rare |
| **Ongoing costs** | Rates, management fees | Property tax, MCST, sinking fund |

**Verdict**: Singapore wins decisively. HDB provides a floor; HK has no equivalent.

### Food — Hong Kong's Clear Win

| Aspect | Hong Kong | Singapore |
|--------|-----------|-----------|
| **Hawker meal** | HK$40-80 / US$5-10 | S$3.50-8 / US$2.60-6 |
| **Mid restaurant** | HK$100-200 / US$13-25 | S$15-30 / US$11-22 |
| **Groceries (monthly)** | HK$4,000-7,000 / US$500-900 | S$400-700 / US$300-500 |
| **Alcohol (retail)** | No duty on wine | High duties (S$88/L alcohol) |
| **Variety/depth** | Intense, 24/7, wet markets | Hawker UNESCO, regulated |

**Verdict**: Hong Kong cheaper for dining out; Singapore cheaper for groceries. HK wins on variety/intensity.

### Transport — Hong Kong Wins for Commuters

| Aspect | Hong Kong | Singapore |
|--------|-----------|-----------|
| **Monthly transit** | HK$500-800 / US$65-100 | S$120-180 / US$90-135 |
| **System quality** | MTR: 99.9% on-time, profitable | MRT: World-class, expanding |
| **Car ownership** | Rare, expensive, impractical | Possible but COE = S$90k/10yr |
| **Taxi/Grab (10km)** | HK$80-120 / US$10-15 | S$15-25 / US$11-18 |
| **Walkability** | High (dense, covered walkways) | High (covered linkways, parks) |

**Verdict**: HK cheaper, slightly better system. SG car ownership possible (unlike HK).

### Taxation — Hong Kong for Cash Flow, Singapore for Wealth Building

| Aspect | Hong Kong | Singapore |
|--------|-----------|-----------|
| **Top income rate** | 15% (standard) / 17% (progressive) | 22% (24% from YA2024) |
| **Effective rate (S$150k)** | ~8-10% | ~6-8% (after reliefs) |
| **Effective rate (S$500k)** | ~13-14% | ~14-16% |
| **Capital gains** | None | None |
| **Dividends** | None | None (one-tier) |
| **Consumption tax** | 0% | 9% GST |
| **Property tax** | 15% on net AV | 0-23% (owner), 11-27% (investment) |
| **Stamp duty (buy)** | Up to 20% (non-PR) | Up to 66% (foreigner) |
| **Wealth/estate tax** | None | None |
| **Forced savings** | MPF: 5%+5% capped HK$18k/yr | CPF: 20%+17% up to S$30k+/yr |

**Verdict**: HK wins on take-home pay. SG CPF builds substantial assets (housing + retirement + medical).

### Healthcare — Different Models

| Aspect | Hong Kong | Singapore |
|--------|-----------|-----------|
| **Public inpatient** | HK$180/day | S$30-150/day (subsidized) |
| **Private inpatient** | HK$5,000-15,000/day | S$500-3,000/day |
| **Insurance (age 35)** | HK$6,000-15,000/yr (VHIS Flexi) | S$400-1,000/yr (IP rider, from MediSave) |
| **Tax relief on premiums** | HK$8,000/yr | MediSave withdrawal limits |
| **Out-of-pocket certainty** | Lower (public cheap) | Higher (mediShield Life limits) |
| **Medical tourism** | Growing | Established hub |

**Verdict**: HK cheaper public access. SG insurance more integrated with savings (MediSave). SG better for private care cost certainty.

## Hidden Cost Differentials

### Hong Kong Hidden Costs
1. **Club memberships**: HK$500k-5M debentures for social/sports
2. **School debentures**: HK$500k-3M for priority
3. **Medical inflation**: 8-10%/yr, VHIS premiums rise sharply with age
4. **Rental volatility**: 10-20% swings common
5. **Exchange rate**: USD peg stable but USD strength = HKD strength

### Singapore Hidden Costs
1. **COE renewal**: S$90k every 10 years (car)
2. **HDB lease decay**: Value drops sharply after 60 years
3. **CPF lock-up**: Can't access until 55/65
4. **GST on everything**: 9% on all consumption
5. **Carbon tax passthrough**: Rising utility/fuel costs
6. **ABSD on 2nd property**: 20-30% for citizens, 60%+ for foreigners

## Break-Even Analysis

**When does Singapore's CPF advantage overcome HK's tax advantage?**

- **Single, <S$100k**: HK wins on cash flow
- **Single, >S$150k**: SG CPF compounding catches up ~5-7 years
- **Family, any income**: SG wins immediately (HDB + child reliefs + CPF)
- **High net worth (>S$5M)**: HK wins (no wealth tax, no ABSD on portfolio)
- **Retiree**: HK wins (entry + 0% consumption tax)

## The "Total Cost of Ownership" View

Over 10 years, for a family earning S$250k/yr:
- **Hong Kong**: ~S$2.5M spent, ~S$500k assets (MPF + investments)
- **Singapore**: ~S$2.0M spent, ~S$1.2M assets (CPF + HDB equity + investments)

**Singapore's forced savings (CPF) + subsidized housing (HDB) create a ~S$700k wealth advantage over a decade** — but at the cost of liquidity and choice.
