**Key Allowances (2024/25)**
- Basic: HK$132,000 (single), HK$264,000 (married)
- Child: HK$130,000 each (+HK$130k year of birth)
- Dependent Parent/Grandparent: HK$55,000-60,000
- Single Parent: HK$132,000
- Disabled Dependent: HK$75,000

**Key Deductions**
- MPF/ORSO: HK$18,000 cap
- VHIS Premiums: HK$8,000 per policy

**Property Tax**: 15% on net assessable value (rental income less 20% statutory deduction)

**Stamp Duty**
- Stock: 0.13% each side (buyer + seller)
- Property: BSD (1.5-4.25%), BSD Non-PR (+15%), SSD (5-15% flip <36m), DSD (varies)

## Corporate Taxation

### Hong Kong
| Aspect | Details |
|--------|---------|
| **Rate** | 8.25% first HK$2M, 16.5% thereafter (two-tier) |
| **Basis** | Territorial — only HK-sourced income taxed |
| **Capital Gains** | Not taxed (unless trading) |
| **Dividends** | Exempt (no withholding) |
| **Interest** | Exempt (non-financial institutions) |
| **Royalties** | 4.95% (individual), 16.5% (corporate) — treaty reduced |
| **Losses** | Carry forward indefinitely, no carry back |
| **Group Relief** | None (but group loss relief proposed) |
| **Transfer Pricing** | OECD-aligned, CbC reporting (MNE >€750M), documentation |
| **Incentives** | R&D super-deduction (300% first HK$2M, 200% thereafter), 100% capex (plant/machinery), re-industrialization, corporate treasury centre, aircraft leasing |

### Singapore
| Aspect | Details |
|--------|---------|
| **Rate** | 17% (headline), effective lower with incentives |
| **Basis** | Territorial (foreign-sourced exempt if taxed ≥15% abroad) |
| **Capital Gains** | Not taxed (unless property trading/dealer) |
| **Dividends** | Exempt (one-tier system) |
| **Interest** | Taxable (unless exempt — SGS, qualifying debt securities) |
| **Royalties** | 10% (treaty reduced to 0-10%) |
| **Losses** | Carry forward indefinitely, carry back 1 year (S$100k cap) |
| **Group Relief** | Yes (75% ownership, same year) |
| **Transfer Pricing** | OECD-aligned, CbC reporting, documentation, APA program |
| **Incentives** | Pioneer (5-15%, 5-10yr), DIP (10%, 5yr), IP Development (5-10%), R&D 250% deduction, Investment Allowance (100%), M&A allowance, Land Intensification |

## International Tax Architecture

### Hong Kong
- **Tax Treaties**: 50+ comprehensive DTAs (China, US, UK, Japan, Singapore, UAE, etc.)
- **MLI**: Signed 2017, ratified 2019 — BEPS implementation
- **CRS**: Implemented 2018 — 100+ jurisdictions, automatic exchange
- **CbC Reporting**: MNE >€750M, filed with IRD
- **Pillar Two**: Domestic minimum top-up tax (15%) effective 2025 — HK companies in MNE groups
- **Beneficial Ownership**: SCR (Significant Controllers Register), AMLO regime
- **Tax Rulings**: Advance rulings available (IRD), bilateral APAs

### Singapore
- **Tax Treaties**: 90+ comprehensive DTAs (broadest in Asia)
- **MLI**: Signed 2017, ratified 2019 — 50+ treaties modified
- **CRS**: Implemented 2018 — 100+ jurisdictions
- **CbC Reporting**: MNE >S$1.125B, filed with IRAS
- **Pillar Two**: Income Inclusion Rule (IIR) + Domestic Top-up Tax (DTT) effective 2025 — MNE ≥€750M
- **Beneficial Ownership**: RORC (Register of Registrable Controllers), VCC register (private)
- **Tax Rulings**: Advance rulings (IRAS), unilateral/bilateral/multilateral APAs, GST rulings

## Wealth Management & Succession

### Hong Kong
- **Trust Law**: Common law based (Trustee Ordinance), perpetuity period abolished (2013), reserved powers, firewall provisions
- **Family Offices**: S.14 profits tax exemption (no approval, 8.25% rate), 2,700+ FOs
- **Insurance**: PPLI/PPVA popular, HK/Offshore wrappers, tax-deferred
- **Succession**: No forced heirship (common law), wills/probate, cross-border via HK-China arrangement (2019)
- **Philanthropy**: Charitable trusts, donor-advised funds, tax deduction 35%

### Singapore
- **Trust Law**: Trustees Act (2004), perpetuity 100 years, reserved powers, firewall (Trust Companies Act), #1 in Asia
- **Family Offices**: 13U (S$1B+ AUM, 5+ investment professionals), 13X (onshore fund), 13CA (non-resident) — tax exemption
- **Insurance**: PPLI/PPVA, SRS wrapper, dedicated funds, tax-deferred
- **Succession**: No forced heirship (except Muslim law), wills/probate, trust planning, FICA compliance
- **Philanthropy**: Charitable trusts, CFS (Community Foundation), tax deduction 250% (qualifying)

## Bottom Line

| Choose Hong Kong If | Choose Singapore If |
|---------------------|---------------------|
| **Zero consumption tax** (no GST/VAT) | **Treaty network** (90+ vs 50+) |
| **Lower personal tax** (15% cap) | **Group relief** (corporate) |
| **No withholding on interest** | **R&D super-deduction** (250%) |
| **RMB internationalization** | **AAA sovereign / currency stability** |
| **China wealth corridor** | **Global wealth preservation** |
| **Territorial purity** (offshore = exempt) | **Foreign-sourced income exemption** (if taxed ≥15%) |
| **Common law trusts** (perpetuity free) | **Statutory trusts** (100yr, firewall, VCC) |
| **Simple compliance** | **Incentive-rich** (if qualified) |

**For the Mobile Professional**: HK wins on take-home pay (tax + no GST). SG wins on forced savings (CPF) + wealth structuring.

**For the Corporation**: HK wins on simplicity + China access. SG wins on incentives + treaty network + IP regime.

**For the Investor**: Both 0% CGT, 0% dividend tax. HK: no withholding on interest. SG: better treaty benefits for cross-border.

**For the Family Office**: HK: simpler, China-connected. SG: deeper ecosystem, VCC, regulatory certainty, succession planning.
